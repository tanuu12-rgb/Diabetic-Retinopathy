AI Diabetic Retinopathy Screening — Working Front-End Prototype

Run:
1. Open index.html in Chrome/Edge.
2. Upload a JPG/PNG fundus image.
3. Click Run Screening.
4. The prototype demonstrates the intended workflow:
   capture -> quality check -> AI analysis -> confidence -> report.

Important:
The quality score and AI result are simulated for demonstration. This is not a clinical diagnostic tool.
To make it a real AI prototype, connect the UI to a validated MATLAB Deep Learning model/API trained and evaluated on APTOS 2019, IDRiD and/or Messidor-2.
